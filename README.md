🌿 Mercado Primavera

Sitio web multipágina desarrollado como caso de estudio de UX/UI, diseño web y desarrollo asistido con IA.

Mercado Primavera es una verdulería ficticia de autoservicio pensada para ofrecer una experiencia diferente: recorrer el local con calma, elegir los productos personalmente, llevar solo la cantidad necesaria y descubrir frutas, verduras y variedades poco habituales.

🔗 Demo online: https://mercado-primavera-gray.vercel.app/

✨ Objetivo del proyecto

El desafío fue crear una experiencia digital que transmitiera la misma sensación que recorrer el local:

elegir con libertad;

entender fácilmente cómo funciona el autoservicio;

descubrir productos de estación y variedades especiales;

acceder rápidamente a información útil;

mantener una experiencia visual cálida, fresca y cercana.

El foco no estuvo solo en crear una web atractiva, sino en construir una experiencia clara, coherente y fácil de recorrer.

🧠 Enfoque UX/UI

Durante el proceso se trabajó especialmente en:

arquitectura de información;

jerarquía visual;

UX Writing;

navegación multipágina;

claridad de los CTA;

reducción de ruido visual;

ritmo y espaciado entre secciones;

diseño responsive;

accesibilidad visual;

coherencia entre contenido, imágenes y acciones.

La estructura fue iterada varias veces observando el sitio a tamaño real y ajustando proporciones, espacios y composición para mejorar la experiencia del usuario.

🎨 Identidad visual

La dirección visual de Mercado Primavera se construyó alrededor de una estética:

cálida;

primaveral;

orgánica;

editorial;

cercana;

diferente a una verdulería tradicional.

Se utilizaron tonos crema, verde profundo, verde suave, coral, amarillo y lila, junto con tipografías serif y sans serif para generar contraste y personalidad.

Las imágenes fueron creadas y seleccionadas para acompañar cada momento del recorrido, evitando que funcionen solo como decoración.

🚀 Deploy

El proyecto está desplegado en Vercel.

Demo:

https://mercado-primavera-gray.vercel.app/

💻 Ejecutar el proyecto localmente

Cloná el repositorio:

git clone https://github.com/mailuduena/mercado-primavera.git

Entrá en la carpeta:

cd mercado-primavera

Instalá las dependencias:

npm install

Ejecutá el entorno de desarrollo:

npm run dev

Para generar el build de producción:

npm run build

📱 Responsive

El sitio fue diseñado para adaptarse a:

desktop;

tablet;

mobile.

La disposición de cards, imágenes, navegación y CTA cambia según el tamaño de pantalla para mantener claridad y legibilidad.
